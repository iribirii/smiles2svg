Contributing

Documentation
-------------

* Theme: `Furo <https://pradyunsg.me/furo/>`_ (configured in ``docs/conf.py``).
* Regenerate gallery SVGs after changing rendering:

  .. code-block:: bash

     python docs/scripts/generate_doc_figures.py
