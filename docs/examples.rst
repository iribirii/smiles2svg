Examples gallery
================

SMILES strings are standard `OpenSMILES <http://opensmiles.org/>`_-style inputs. Below, figures use the documented defaults (``canvas_size=640``, ``padding=16`` in the gallery generator).

Drugs and larger structures

.. list-table::

   * - .. image:: _static/images/aspirin.svg
          :width: 320px
     - **Aspirin (acetylsalicylic acid)** — ``CC(=O)Oc1ccccc1C(=O)O`` (``names_hetero``)

Reproduce locally
-----------------

.. code-block:: bash

   smiles2svg -s 'CC(=O)Oc1ccccc1C(=O)O' --style names_hetero -n aspirin

Figures are generated by ``docs/scripts/generate_doc_figures.py``.
